Postsiva runs **two** Streamable HTTP MCP endpoints:

| Audience | Endpoint | Auth |
|----------|----------|------|
| **CLI** (Cursor, Claude Code) | `https://mcp.postsiva.com/mcp` | API key header (or OAuth) |
| **Web** (Claude.ai, ChatGPT MCP Apps) | `https://mcp.postsiva.com/web/mcp` | OAuth (recommended) or API key |

Stateless — no session between calls. Built-in host search is used instead of an MCP search tool.

## Authentication

**API key** (CLI-friendly):

| Method | Example |
|--------|---------|
| Header | `X-API-Key: psk_live_YOUR_KEY` |
| Query param | `https://mcp.postsiva.com/mcp?api-key=psk_live_YOUR_KEY` |

Also accepted: `?apikey=` / `?api_key=` (same key).

The key must belong to a workspace on the **Pro** plan with MCP enabled.

**OAuth:** Claude.ai / ChatGPT connect via Connectors — JWT audience must match the MCP URL (`/mcp` or `/web/mcp`).

### Errors

Missing or invalid key → tool result with error message (e.g. *"API key required"* or *"Invalid or expired API key"*).

Wrong plan → upgrade message referencing postsiva.com.

## Cursor

1. **Cursor Settings → MCP → Add server**
2. Type: **HTTP** (Streamable HTTP)
3. URL: `https://mcp.postsiva.com/mcp` (**CLI**)
4. Headers: `X-API-Key` = your `psk_live_…` key
5. Restart Cursor or reload MCP

Or in `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "Postsiva": {
      "url": "https://mcp.postsiva.com/mcp",
      "headers": {
        "X-API-Key": "psk_live_YOUR_KEY"
      }
    }
  }
}
```

## Claude Code

```bash
claude mcp add --transport http postsiva https://mcp.postsiva.com/mcp \
  --header "X-API-Key: psk_live_YOUR_KEY"
```

## Claude.ai (custom connector)

1. **Settings → Connectors → Add connector → Add custom connector**
2. **Name:** `Postsiva`
3. **URL:** `https://mcp.postsiva.com/web/mcp` (**Web** — iframe upload)
4. Connect with OAuth (prefer no API key in the URL)

Full walkthrough: [Claude](/integrations/claude).

## Verify connection

## Media upload

| MCP | Flow |
|-----|------|
| Web `/web/mcp` | `upload_media` → iframe → Postsiva storage → `media_id` / `public_url` → `publish` |
| CLI `/mcp` | `upload_media(file_path=…)` → run `curl_command` → `media_id` / `public_url` → `publish` |
